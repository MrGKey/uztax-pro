    Technical Architecture
    Современный стек технологий с фокусом на безопасность и производительность
    ⚙️
    Tech Stack
  • Frontend: React 18 + Vite + TypeScript
  • Backend: Python FastAPI + aiogram 3
  • Database: Neon PostgreSQL (pg8000)
  • Auth: Telegram Init Data (HMAC SHA-256)
  • Hosting: Render (Static + Web Service)
  • CDN: Cloudflare
    • 🔒
    Security & Compliance
  • HTTPS / TLS — всегда
  • CSP + HSTS + X-Frame-Options
  • Rate Limiting: 30 req/min
  • Parameterized SQL — injection protection
  • Закон РУз №547 — consent + data export/delete
  • Audit logging всех POST/PUT/DELETE
    • System Architecture
    Telegram
    ├── Bot (@SoliqPay_bot) — polling
    └── Mini App — Frontend (CDN)
    └── Cloudflare
    └── Render Static Site
    API
    └── Render Web Service (FastAPI)
    ├── Row-Level Security (per user)
    └── Neon PostgreSQL
    Total: ~240 files, ~3,600 lines of code
